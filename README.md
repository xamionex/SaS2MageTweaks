# SaS2MageTweaks

Configurable tweaks for mage hunts: skip hunt phases, adjust how many minions mages summon during fights, modify their loot drops and health, configurable using [Mod Options](https://www.nexusmods.com/saltandsacrifice/mods/40)

All options default to vanilla behavior.

Made with https://github.com/xamionex/SaltAndSacrificeBepInExTemplate
